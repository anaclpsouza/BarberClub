# Barber Club

Landing Page estática desenvolvida para uma barbearia moderna e premium.

## Tecnologias
- **HTML5 Semântico**
- **CSS3 Vanilla** (Variáveis Globais, Flexbox, CSS Grid)
- **Zero JavaScript** (Toda a interatividade e responsividade são tratadas nativamente via CSS)

## Estrutura da Página
O projeto consiste em uma *Single Page* com arquitetura focada em **Mobile First**, contemplando as seguintes seções:
1. **Home (Hero)**: Área de impacto visual inicial.
2. **Sobre**: Identidade visual e métricas da barbearia.
3. **Serviços**: Tabela estática de serviços e preços.
4. **Profissionais**: Apresentação da equipe.
5. **Galeria**: Mosaico fotográfico em CSS Grid.

*(As telas complementares de Agendamento, Planos e Confirmação integram a estrutura conceitual do fluxo mapeado).*

## Como Executar
Por ser um projeto puramente estático, basta clonar o repositório e abrir o arquivo `index.html` em seu navegador.
